# aipm-delegate — aipm derivative

This distribution enables only Codex. Read-only is the default; implementation uses the workspace-write sandbox. Upstream runner/session/result handling is retained, with bounded permissions and an explicit task-contract router.

See [SKILL.md](SKILL.md) and [Codex runner notes](references/runners.md). Original multi-provider tests and documentation are retained separately under the package upstream directory; their Windows failures are recorded, not presented as passing tests for this derivative.
