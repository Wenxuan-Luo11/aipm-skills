# 验证记录与支持范围

## 可重复的确定性检查

```sh
python scripts/check.py --force
```

检查包括清单/名称、资源相对路径、许可、46项锁定上游文件字节哈希、20项本包单测以及Git空白检查。测试覆盖安装预览、冲突和修改保留、旧名称卸载、路径拒绝、角色/模型档位、续接沙箱参数、完成事件及本地证据失效。公开发行副本的检查与CI结果以本仓库对应提交为准。

本地证据只有输入内容、命令、环境、HEAD、工作区/暂存diff与空白配置匹配时才复用；失败不缓存、不自动重试。CI始终新跑。缓存记录是可信本地状态，不能作为防伪证明。

曾发现上游快照在Git换行转换后哈希不匹配；用 upstream/** -text 保留原字节，不修改锁文件或放宽校验。曾发现缓存遗漏Git基线/空白配置；有修前失败、修后通过的回归。

## 真实执行与行为探针

早版Codex只读新会话及续接曾成功；最新版续接绑定变更未完成真实端到端复测。请求型号与实际型号分开记录，事件缺少型号时不得声称已证实。结构校验和dry-run不能替代真实调用。

历史上有三类匿名行为探针：完成体验、事件推断、交付证据。各一组无Skill/有Skill，共六个隔离会话；均退出0且有turn.completed，两组都识别核心证据缺口。该批有指导文本乱码和重复读取，实际型号未从事件证实；更早的一批受父目录规则污染，不用于比较。未重复运行或筛掉失败样本，不能得出增益/节省结论。原始日志、会话ID和环境路径不公开。

## Beta限制

- 仅支持适配的Codex执行路径，不承诺全部上游runner兼容；上游Windows假CLI测试曾失败，不能将完整快照等同宿主兼容。
- 状态目录需串行操作；allowed_paths是工作合同，不是逐文件硬沙箱。
- 官方quick_validate早期有通过记录，但后续本地PyYAML不可用时未重跑；新版使用本包validator，不把历史官方记录称为新版通过。
- 许可证/哈希检查不是供应链安全认证。跨项目效果、真实用户结果及节省率未验证。
