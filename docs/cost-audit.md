## 下一批工作的规划估计（非实测）

旧截面缓存输入占比约 98.9%，非缓存输入 603,964。若假设短交接和摘要减少 40% 缓存输入、20% 非缓存输入，输出不变，累计输入将减少约 39.8%，非缓存输入加输出则减少约 15.6%。这是条件算式，不是已经实现的收益；新任务缓存比例可能不同。

在相似长任务中，可暂用“累计输入减少 20%–40%，墙钟时间减少 5%–20%”做低置信度规划区间，依据是假设减少重复读取和无效验证，不包含部署/人工等待的固定部分；小任务或冷启动可能无收益甚至变慢。未来以质量相同的真实任务更新，不能把该区间写成产品效果。

费用只能按实际型号的非缓存输入价、缓存输入价、输出价加权：成本 = 非缓存输入 × 输入价 + 缓存输入 × 缓存价 + 输出 × 输出价。本次不掌握实际账单及新任务型号，故不估费用/订阅额度节省率。CI 去重可减少同一 feature 提交的重复运行（原 push+PR 两次改为 PR 一次），不代表总研发时间减半。
